# Requirements

## Functional Requirements

- Accept two text inputs from user
- Preprocess text (clean, tokenize, remove stopwords, lemmatize)
- Calculate TF-IDF vectors
- Compute cosine similarity
- Classify as Duplicate / Similar / Different
- Display similarity score as percentage

## Non-Functional Requirements

- Python 3.10+
- NLTK for text preprocessing
- Scikit-learn for TF-IDF and similarity
- Streamlit for UI
- Response time < 2 seconds per comparison
