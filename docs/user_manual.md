# User Manual

## How to Use

1. Run the application: `streamlit run app/ui/streamlit_app.py`
2. Enter two sentences or questions in the text areas
3. Click "Compare Texts"
4. View similarity score and classification
5. Use batch comparison to check against sample questions

## Classification

- **Duplicate:** Score ≥ 80% (🔴)
- **Similar:** Score ≥ 50% (🟡)
- **Different:** Score < 50% (🟢)
